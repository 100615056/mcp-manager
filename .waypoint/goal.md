# Goal

Build @waycraft/mcp-manager: a standalone Node.js/TypeScript MCP server and tray daemon that monitors all configured MCP servers, surfaces connection health, fires native desktop notifications on drop/reconnect, and auto-restarts crashed stdio processes. Core tools: mcp_status, mcp_restart, mcp_restart_all, mcp_history, mcp_config. Reads config from claude_desktop_config.json / .mcp.json. Pings each stdio server every 10s, auto-restarts up to 3 times with exponential backoff. Exposes status at localhost:3131/status. Tech stack: Node.js 18+, TypeScript, @modelcontextprotocol/sdk, node-notifier, execa, zod.
